## Lot 10a : sécurité des données (rien ne doit se perdre)

1. 🔴 **Une erreur de lecture est prise pour une base vide**, et l'app re-sème le grow de départ par-dessus les vraies données (`grow/main`, `cycle-1`, espaces, équipement).
   - Code : `artifact-store.ts`, `grow-context.tsx:135-150`.
   - Correctif : distinguer erreur et vide ; ne semer qu'après une lecture réussie et vraiment vide. [UI, SEC]
2. 🔴 **Version Claude : si `use("db")` échoue, bascule silencieuse sur un stockage local** de l'artefact.
   - Code : `store/index.ts`.
   - Correctif : afficher une erreur avec un bouton Réessayer. [CALC]
3. 🔴 **Un document mal formé (import, base) bloque l'app à chaque ouverture**, car les tris `localeCompare` plantent sur un champ absent.
   - Correctif : tris tolérants, validation par collection à l'import, écran d'erreur avec « Exporter les données brutes » et « Réinitialiser ». [CALC, SEC]
4. 🔴 **Import en mode « Remplacer »** : les suppressions passent avant les écritures, sans confirmation ni copie de secours.
   - Correctif : écrire d'abord, supprimer ensuite ; sauvegarde automatique avant le remplacement ; boîte de confirmation. [SEC, CALC, UX]
5. 🔴 **Une saisie vide est enregistrée** : toast « Enregistrée » et « Tout est dans la cible », alors que cette saisie vide masque la saisie précédente.
   - Correctif : refuser une saisie sans aucune valeur. [UX]
6. 🟠 **Export, réinitialisation et import incomplets sans le dire** : `list()` avale les erreurs.
   - Correctif : lever l'erreur dans ces trois cas. [UI, SEC, CALC]
7. 🟠 **Une écriture refusée reste visible** en mémoire jusqu'au rechargement.
   - Correctif : écrire dans IndexedDB d'abord. [UI, SEC]
8. 🟠 **IndexedDB indisponible = chargement infini.**
   - Correctif : message clair et repli. [UI, SEC, CALC]
9. 🟠 **Double appui = bidon ou pulvérisation enregistré deux fois.**
   - Correctif : garde `busy` sur Nutrition et IPW. [UI]
10. 🟠 **Une suppression ratée ferme le dialogue sans rien dire.**
    - Correctif : try/catch et toast d'erreur. [UI]
11. 🟠 **Un nombre mal tapé est enregistré vide** avec le toast « Enregistré ».
    - Correctif : signaler le champ et bloquer. [UI]
12. 🟠 **Import plus robuste.** [SEC]
    - try/catch global ;
    - limite de taille (~20 Mo) ;
    - `Object.hasOwn` ;
    - vidage du champ fichier après Annuler.
13. 🟠 **Plusieurs onglets ou l'app installée s'écrasent mutuellement.**
    - Correctif : `BroadcastChannel` qui recharge les données. [SEC]
14. 🟠 **Photos jamais supprimées** (ni au retrait, ni à la suppression d'une saisie, ni à la réinitialisation de l'artefact). [UI, SEC]
15. 🟠 **Rappel de sauvegarde remis à zéro sans vraie sauvegarde** (par un simple « Copier », ou quand le téléchargement iOS échoue). [SEC]
16. 🟠 **Import et réinitialisation quadratiques** (3 000 docs ≈ 23 s).
    - Correctif : écriture par lot, un seul `emit`. [SEC]
17. ⚪ **Couleur d'espace non filtrée** : injection CSS possible.
    - Correctif : n'accepter que `SPACE_COLORS`. [SEC]
18. ⚪ **CSV.** [SEC, UI, CALC]

19. ⚪ **.ics.** [SEC, CALC]

21. ⚪ **Stockage protégé.** [SEC]
